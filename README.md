**Backend .NET · C# · SQL · València / remoto**

Siete años escribiendo backend. Tres empresas, tres productos que se usan a diario: la red de 1.500 tiendas de una cadena de alimentación, el SCADA de 96 parques eólicos y 24 plantas fotovoltaicas, y una plataforma .NET para importadores y concesionarios de vehículos.
